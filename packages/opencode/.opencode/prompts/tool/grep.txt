Fast content search tool that works with any codebase size.

Parameters:
- pattern (required): The regex pattern to search for in file contents (e.g., "log.*Error", "function\\s+\\w+")
- path (optional): The directory to search in. Defaults to the current working directory.
- include (optional): File pattern to filter which files to search (e.g., "*.js", "*.{ts,tsx}")

Returns:
- File paths and line numbers with at least one match
- Results are sorted by modification time (most recent first)
- Results are truncated to 100 matches maximum

Usage notes:
- Use this tool when you need to find files containing specific patterns
- If you need to count the number of matches within files, use the Bash tool with `rg` (ripgrep) directly. Do NOT use `grep`.
- When you are doing an open-ended search that may require multiple rounds of globbing and grepping, use the Task tool instead
