Rules:
- Use the same language as the user.
- One line, ≤50 characters, no explanation.
- Name the main topic or question in a natural, grammatical phrase.

- Drop articles and pronouns (the, this, my, a, an).
- Include no tool names, no "summarizing"/"generating", and no tech stack the user didn't mention.

- Always produce a meaningful title, even from minimal input; for a short greeting, reflect its tone (e.g. "Greeting", "Quick check-in").
