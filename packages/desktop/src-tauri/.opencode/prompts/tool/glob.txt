Fast file pattern matching tool that works with any codebase size.

Parameters:
- pattern (required): The glob pattern to match files against (e.g., "**/*.js" or "src/**/*.ts")
- path (optional): The directory to search in. Defaults to the current working directory.

Returns:
- Matching file paths sorted by modification time (most recent first)
- Results are truncated to 100 files maximum

Usage notes:
- Use this tool when you need to find files by name patterns
- When you are doing an open-ended search that may require multiple rounds of globbing and grepping, use the Task tool instead
- You can call multiple tools in a single response; it is always better to speculatively perform multiple searches as a batch that are potentially useful
