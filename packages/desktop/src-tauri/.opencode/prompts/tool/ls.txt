Lists files and directories in a given directory with a tree-like structure.

Parameters:
- path (optional): The absolute path to the directory to list. If omitted, uses the current workspace directory.
- ignore (optional): An array of glob patterns to exclude from the listing.

Usage notes:
- The path parameter must be absolute (start with /), not relative
- Results are limited to 100 files maximum
- Common ignore patterns are already applied (node_modules, .git, dist, etc.)
- Directories are shown with a trailing / and listed before files
- Files within each directory are sorted alphabetically

You should prefer the Glob tool if you need to search for specific files by pattern, or the Grep tool if you need to search file contents.
